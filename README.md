# 🚀 TechNova - Responsive Business Landing Page

## 📌 DecodeLabs Internship Task 1

This project was developed as part of the DecodeLabs Web Development Internship Program.

### Task Objective
Build a modern and responsive business landing page using HTML, CSS, and JavaScript while implementing:

- Responsive web design principles
- Interactive navigation system
- Modern UI/UX layout
- Mobile-friendly interface
- JavaScript DOM manipulation
- Professional project structure

---

## 📖 Project Overview

TechNova is a modern business landing page designed for startups and technology companies. The website provides a clean and engaging user experience while showcasing services, company information, and contact options.

---

## ✨ Features

- Fully Responsive Design
- Mobile Navigation Menu
- Scroll Spy Navigation
- Modern Glassmorphism UI
- Interactive Icons using Lucide
- Hero Section with CTA Buttons
- Services Showcase
- Mission & About Section
- Statistics Section
- Contact Form Layout
- Professional Footer

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Lucide Icons
- Google Fonts
